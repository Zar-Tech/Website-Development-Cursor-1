# Unity Script Starter Set

These scripts are starter references for the production Unity project. Copy them into a Unity 2D project under `Assets/Scripts/TowerDefenseLite/`.

They assume a standard Unity project with:

- 2D physics enabled.
- Portrait orientation.
- Prefabs for enemies, towers, build nodes, and projectiles.
- ScriptableObjects for tower, enemy, wave, and level tuning.

The browser prototype in the parent folder is the playable reference. These scripts define the Unity-side shape for the first production milestone.
